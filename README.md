# 주식 정보 API 서버

Flask 기반으로 만들어진 간단한 주식 정보 제공 API 서버입니다. 한국 상장 회사명을 입력받아 관련 주식 데이터, 재무 정보, 기술적 지표, 최신 뉴스 등을 조회하는 기능을 제공합니다.

## 주요 기능

*   **회사 정보 조회:** 회사명으로 티커 심볼, 업종, 웹사이트 등 기본 정보 조회 (SQLite DB 사용)
*   **주가 데이터:** `yfinance` 라이브러리를 사용하여 기간별(예: 1일, 1개월, 1년) 주가(종가) 및 변동률 조회
*   **재무 데이터:** `yfinance`를 통해 매출, 영업이익, 순이익, PER, PBR, ROE 등 주요 재무 지표 조회
*   **기술적 지표:** 이동평균선(MA), 볼린저 밴드 등 기본적인 기술적 지표 계산 및 제공
*   **최신 뉴스:** 네이버 뉴스 검색 결과를 스크래핑하여 해당 회사의 최신 뉴스 10개 제공
*   **유사 회사명 검색:** 입력된 회사명과 유사한 이름을 가진 회사를 찾아 티커 반환 (오타 또는 약칭 대응)
*   **재무 추세:** 최근 4개년 재무 데이터(매출, 영업이익, 순이익, 이익률) 추세 제공

## 사전 준비 사항

*   **Python 3.x:** 파이썬 인터프리터가 설치되어 있어야 합니다.
*   **pip:** 파이썬 패키지 관리자가 설치되어 있어야 합니다.
*   **회사 정보 CSV 파일 (`company.csv`):** 프로젝트 루트 디렉토리에 `company.csv` 파일이 필요합니다. 이 파일은 최소한 다음 컬럼을 포함해야 합니다:
    *   `회사명`: 회사의 전체 이름
    *   `종목코드`: 6자리 숫자 코드
    *   `티커`: yfinance에서 사용할 티커 (예: 005930.KS)
    *   `시장구분`: KOSPI 또는 KOSDAQ
    *   `업종`: 회사의 주 업종
    *   `주요제품`: 회사의 주요 제품 또는 서비스
    *   `홈페이지`: 회사 웹사이트 주소 (선택 사항)
    *   `alias`: 회사의 다른 이름 또는 약칭 (선택 사항, 검색 정확도 향상용)
    *   (기타 `create_db_if_not_exists` 함수에서 사용하는 컬럼들)

## 설치 및 실행

1.  **저장소 복제:**
    ```bash
    git clone https://github.com/SomersetMaugham/StockApiServer.git
    cd <프로젝트_디렉토리>
    ```

2.  **필요 라이브러리 설치:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **데이터베이스 생성:**
    *   프로젝트 루트 디렉토리에 `company.csv` 파일을 위치시킵니다.
    *   서버를 처음 실행하면 `app.py` 내의 `create_db_if_not_exists` 함수가 자동으로 `company.csv` 파일을 읽어 `stock_info.db` 라는 SQLite 데이터베이스 파일을 생성합니다.
    *   만약 `stock_info.db` 파일이 이미 존재하면 이 단계는 건너띄고, 진행됩니다.

4.  **서버 실행:**
    ```bash
    python app.py
    ```
    *   기본적으로 `http://0.0.0.0:5000` 에서 서버가 실행됩니다.

## API 엔드포인트

*   **`GET /status`**: 서버의 현재 상태 및 타임스탬프를 반환합니다.
*   **`GET /api/company?name=<회사명>`**: 지정된 회사명에 대한 종합적인 정보(기본 정보, 현재가, 주가 데이터, 재무 데이터, 기술적 지표, 뉴스)를 JSON 형식으로 반환합니다.
    *   예: `/api/company?name=삼성전자`
*   **`GET /api/stock?name=<회사명>&range=<기간>`**: 지정된 회사명과 기간(예: `1d`, `1mo`, `1y`, `max`)에 해당하는 주가 데이터를 JSON 형식으로 반환합니다.
    *   예: `/api/stock?name=삼성전자&range=1mo`
*   **`GET /api/technical?name=<회사명>&indicators=<지표1>&indicators=<지표2>...`**: 지정된 회사명에 대한 특정 기술적 지표 데이터를 JSON 형식으로 반환합니다.
    *   `indicators` 파라미터로 `ma` (MA20, MA60), `bollinger` (볼린저 밴드 상단/하단) 등을 지정할 수 있습니다.
    *   예: `/api/technical?name=삼성전자&indicators=ma&indicators=bollinger`
*   **`GET /api/financial_trend?name=<회사명>`**: 지정된 회사명의 최근 4개년 재무 추세(매출, 영업이익, 순이익, 이익률) 데이터를 JSON 형식으로 반환합니다.
    *   예: `/api/financial_trend?name=삼성전자`

## 참고 사항

*   뉴스 데이터는 네이버 뉴스 검색 결과를 스크래핑하므로, 네이버 웹사이트 구조 변경 시 작동하지 않을 수 있습니다.
*   주가 및 재무 데이터는 `yfinance` 라이브러리에 의존하며, 데이터 제공 지연 또는 오류가 발생할 수 있습니다.
*   데이터 조회 실패 시 일부 기능은 샘플 데이터를 반환할 수 있습니다.
*   회사명 검색 시 정확한 티커를 찾지 못하면 유사도(Jaro-Winkler) 기반으로 가장 비슷한 회사를 찾아 반환합니다.
